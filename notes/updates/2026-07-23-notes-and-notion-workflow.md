Added a repository-local `notes/` hierarchy and a matching Notion documentation
page so implemented changes, planned features, and technical decisions have
durable, searchable records.

## Affected areas

- `AGENTS.md`
- `notes/`
- [AI-APP Engineering Notes](https://app.notion.com/p/3a65615a45578113b272cfb82c0ff235)

no existing AI-APP documentation hub or documentation database was found.
