# AI Harness 0.1.7 Windows release

Published the `0.1.7` Windows desktop release with bundled Codex runtime update
reporting and the fail-closed Windows signing pipeline.

## Release contents

- Packaged application version: `0.1.7`
- Bundled Codex CLI version: `0.145.0`
- GitHub release:
  [`v0.1.7`](https://github.com/Zain-Repo/ai-harness-releases/releases/tag/v0.1.7)
- Updater assets: installer, blockmap, `latest.yml`, and
  `codex-runtime.json`

## Validation

- The exact release commit passed 72 Vitest tests across 26 files, TypeScript
  type checking, the production build, focused ESLint, and signing preflight.
- `bun run installer:windows` produced the packaged application and NSIS
  updater from the clean release commit.
- All 16 packaged PE files have the expected `CN=AI Harness Test` signer and
  DigiCert timestamp countersignatures. Windows reports the expected
  `UnknownError` trust status because the signer is self-signed.
- The packaged application reports version `0.1.7`; its bundled executable
  reports `codex-cli 0.145.0`, matching the latest stable npm registry version
  at publication time.
- GitHub reports `v0.1.7` as the latest, non-draft, non-prerelease release with
  exactly four uploaded assets.
- GitHub's remote SHA-256 digests and sizes match the local artifacts. The
  installer SHA-256 is
  `2b5710c2b5ccb66f778d5b98c8d30c6d97e9c6bdc5c498b45567162a2a63c2c6`.
- The public `latest.yml` and `codex-runtime.json` assets returned HTTP 200.

## Limitation

The configured certificate is self-signed and does not provide public Windows
trust. The release is signed and timestamped, but users will still receive the
Windows unknown-publisher warning until an identity-validated certificate is
configured.
