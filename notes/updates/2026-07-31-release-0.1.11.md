# AI Harness 0.1.11 release

## Outcome

Prepared AI Harness `0.1.11` for the next Windows desktop release. The
desktop authentication window now recognizes only the configured Clerk
callback hosts as completion handoffs, while GitHub remains available only as
an OAuth navigation origin. The release also includes the current branding
assets and repository Codex review guidance.

## Affected areas

- `package.json` advances the application version to `0.1.11`.
- `electron/main/desktop-navigation.ts` and its tests restrict callback
  completion to the configured Clerk hosts.
- `electron/main/index.ts` closes the authentication window once the callback
  handoff completes.
- `public/branding/` and `public/media/ai-harness-icon-v2.png` contain the
  included branding assets.
- `.github/pull_request_template.md` and `AGENTS.md` document the Codex review
  workflow.

## Validation

- `bun run typecheck`
- `bun run test` — 31 files, 108 tests passed
- `bun run build`
- Prettier check for the changed source, workflow, metadata, and note files
- `git diff --check`

## Release behavior

Pushing this commit to `master` starts the repository CI workflow. After CI
validation succeeds, the workflow invokes the reusable Windows release job
for the exact tested commit and publishes the `v0.1.11` installer assets.
