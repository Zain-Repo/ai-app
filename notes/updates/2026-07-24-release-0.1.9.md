# AI Harness 0.1.9 Windows release

Published the official `0.1.9` Windows desktop release with the current
production web client and the latest desktop fixes.

## Included changes

- Desktop ChatGPT subscription responses collect Codex
  `item/completed` notifications when the final turn omits its items.
- Failed assistant messages identify their actual provider.
- The Microsoft Store AppX packaging path and Store-managed update boundary are
  included in source while NSIS remains the direct-download update channel.
- The packaged application includes Codex CLI `0.145.0`.

## Known limitation

The configured publisher is the self-signed `CN=AI Harness Test` certificate.
Signatures and timestamps are present, but Windows can still show an
unknown-publisher warning on direct downloads because the certificate chain is
not publicly trusted. The Microsoft Store package is a separate distribution
path and was not submitted as part of this NSIS release.
