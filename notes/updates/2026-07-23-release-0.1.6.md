# AI Harness 0.1.6 Windows release

Prepared the `0.1.6` Windows desktop release with the open-source signing
pipeline.

## Validation

- `bun run package:client` and `bun run installer:nsis` succeeded.
- All 16 current PE files and DigiCert RFC 3161 timestamps passed independent
  `osslsigncode` verification.
- The packaged application, `latest.yml`, and blockmap report version `0.1.6`.
- TypeScript, 71 Vitest tests, focused ESLint, focused Prettier, and
  `git diff --check` passed.
- GitHub release
  [`v0.1.6`](https://github.com/Zain-Repo/ai-harness-releases/releases/tag/v0.1.6)
  is latest and contains exactly the installer, blockmap, and updater manifest.
- All remote asset sizes and SHA-256 digests match the local build. The
  installer SHA-256 is
  `5de863ec49c6e979e6797236e507e8caddb4ecc9a4ebfedab18bbef8f42b838c`.

## Limitation

The configured certificate is self-signed and does not provide public Windows
trust.
