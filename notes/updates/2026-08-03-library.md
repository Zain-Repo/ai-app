# Library

Implemented a Library workspace that shows the authenticated user's chat
uploads, project files, and generated images in a paginated date trail.

## Changes

- Added Library navigation, filename search, content filters, date grouping,
  previews, downloads, loading/empty states, and responsive layouts.
- Added links back to the originating project or exact chat message.
- Added an owner-scoped `libraryAssets` index with signed URLs resolved only
  after authorization.
- Indexed new assets transactionally and removed their index records when the
  originating conversation, project, or project source is deleted.
- Added resumable, idempotent migrations for historical messages and project
  files.

## Backfill

After deploying the schema and live writers, run each migration as a dry run,
then run it without `dryRun`:

```powershell
bunx convex run migrations:backfillLibraryFromMessages '{"dryRun":true}'
bunx convex run migrations:backfillLibraryFromProjectSources '{"dryRun":true}'
bunx convex run migrations:backfillLibraryFromMessages
bunx convex run migrations:backfillLibraryFromProjectSources
```

Use `--prod` only during an approved production rollout. No historical
backfill was run as part of this change.
