# AI Harness 0.1.8 Windows release

Published the official `0.1.8` Windows desktop release after restoring updater
compatibility with unsigned installations and allowing the configured
self-signed Authenticode publisher through the release pipeline.

## Release contents

- Source commit:
  [`0735dd8`](https://github.com/Zain-Repo/ai-app/commit/0735dd8)
- GitHub release:
  [`v0.1.8`](https://github.com/Zain-Repo/ai-harness-releases/releases/tag/v0.1.8)
- Bundled Codex CLI: `0.145.0`
- Assets: installer, blockmap, `latest.yml`, and `codex-runtime.json`

## Updater behavior

- New packages omit `publisherName` from `app-update.yml`, matching the
  unsigned-release behavior in `electron-updater`.
- Download integrity remains enforced by the SHA-512 values in `latest.yml`.
- Release binaries are still Authenticode-signed and checked against the
  configured publisher before publication.
- The previous `v0.1.8-manual` prerelease remains as a superseded historical
  test artifact and points users to the official release.

## Compatibility limitation

Unsigned builds without a publisher pin and version `0.1.8` use the automatic
updater normally. Versions `0.1.5` through `0.1.7` already shipped with a
publisher pin and reject the self-signed certificate unless it is trusted
locally; those installations require one manual update to `0.1.8`. An
identity-validated certificate remains required to remove the Windows
unknown-publisher warning.
